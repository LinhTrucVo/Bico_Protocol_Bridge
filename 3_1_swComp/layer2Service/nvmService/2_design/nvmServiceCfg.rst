nvmServiceCfg.h
########################

Defines compile-time feature flags for the NVM Service:

- ``BPB_NVM_SERVICE_CFG_ENABLE_COMPRESSION``: Enables data compression before writing to NVM.
- ``BPB_NVM_SERVICE_CFG_ENABLE_ENCRYPTION``: Enables data encryption before writing to NVM.
