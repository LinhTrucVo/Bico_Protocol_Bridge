spiSlaveDriverCfg.h
########################

Defines compile-time feature flags for the SPI Slave Driver:

- ``BPB_SPI_SLAVE_CFG_ENABLE_DMA``: Enables DMA-based SPI transfers.
- ``BPB_SPI_SLAVE_CFG_ENABLE_CALLBACKS``: Enables RX and TX callback registration.
