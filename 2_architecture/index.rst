=============================
System Architecture
=============================

This section describes the architectural design of the Bico Protocol Bridge system. The architecture is organized to provide clear separation of concerns across multiple layers, from low-level hardware drivers to high-level application logic.

The architecture documentation includes:

- **Functional View**: Detailed description of the three-layer architecture (Drivers, Services, Applications), information flow, and design principles
