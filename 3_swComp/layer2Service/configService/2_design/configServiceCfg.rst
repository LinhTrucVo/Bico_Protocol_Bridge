configServiceCfg.h
########################

Defines compile-time feature flags for the Config Service:

- ``BPB_CONFIG_SERVICE_CFG_ENABLE_SERIAL_CONFIG``: Enables storage and retrieval of serial port configuration.
- ``BPB_CONFIG_SERVICE_CFG_ENABLE_ANALOG_CONFIG``: Enables storage and retrieval of analog channel configuration.
- ``BPB_CONFIG_SERVICE_CFG_ENABLE_PWM_CONFIG``: Enables storage and retrieval of PWM channel configuration.
