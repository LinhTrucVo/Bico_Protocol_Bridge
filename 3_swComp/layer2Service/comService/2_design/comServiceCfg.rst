comServiceCfg.h
########################

Defines compile-time configuration for the ComService:

- ``COMSERVICE_CFG_RX_BUFFER_SIZE``: Size of the Rx ring-buffer in bytes.
- ``COMSERVICE_CFG_TX_BUFFER_SIZE``: Size of the Tx ring-buffer in bytes.
- ``COMSERVICE_CFG_MAX_FRAME_SIZE``: Maximum single frame size in bytes.
