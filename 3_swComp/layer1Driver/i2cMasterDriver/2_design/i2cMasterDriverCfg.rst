i2cMasterDriverCfg.h
########################

Defines compile-time feature flags for the I2C Master Driver:

- ``I2C_MASTER_CFG_ENABLE_DMA``: Enables DMA-based I2C transfers.
- ``I2C_MASTER_CFG_ENABLE_TIMEOUT``: Enables timeout mechanism for blocking transfers.
