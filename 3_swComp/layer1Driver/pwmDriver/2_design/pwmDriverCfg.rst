pwmDriverCfg.h
########################

Defines compile-time feature flags for the PWM Driver:

- ``BPB_PWM_CFG_ENABLE_DMA``: Enables DMA-based PWM waveform generation.
- ``BPB_PWM_CFG_ENABLE_DEAD_TIME``: Enables dead-time insertion for complementary channel outputs.
