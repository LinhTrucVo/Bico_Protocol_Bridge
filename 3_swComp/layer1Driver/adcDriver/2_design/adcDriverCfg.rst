adcDriverCfg.h
########################

Defines compile-time feature flags for the ADC Driver:

- ``ADC_CFG_ENABLE_DMA``: Enables DMA-based sample transfer.
- ``ADC_CFG_ENABLE_INTERRUPTS``: Enables interrupt-driven conversion completion.
- ``ADC_CFG_ENABLE_CALLBACKS``: Enables conversion-complete callback registration.
