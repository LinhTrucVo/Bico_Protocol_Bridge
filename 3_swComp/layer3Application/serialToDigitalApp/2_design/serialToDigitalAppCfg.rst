serialToDigitalAppCfg.h
########################

Defines compile-time feature flags for the Serial-to-Digital Application:

- ``SERIAL_TO_DIGITAL_CFG_ENABLE_PWM``: Enables PWM channel control via serial commands.
- ``SERIAL_TO_DIGITAL_CFG_ENABLE_GPIO``: Enables GPIO pin read/write via serial commands.
