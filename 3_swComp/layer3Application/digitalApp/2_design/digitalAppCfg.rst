DIGITALAPPCfg.h
########################

Defines compile-time configuration for the Serial-to-Digital Application:

- ``SERIAL_TO_DIGITAL_CFG_MAX_GPIO_PINS``: Maximum number of GPIO pins supported.
- ``SERIAL_TO_DIGITAL_CFG_MAX_PWM_CHANNELS``: Maximum number of PWM channels supported.
