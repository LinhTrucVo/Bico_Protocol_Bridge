centralAppControllerCfg.h
########################

Defines compile-time feature flags for the Central Application Controller:

- ``CENTRAL_APP_CFG_ENABLE_ERROR_LOGGING``: Enables error logging and error callback invocation on faults.
- ``CENTRAL_APP_CFG_ENABLE_STATE_MACHINE``: Enables the internal state machine for processing and idle state tracking.
